Autoryzacja

Katalog, wycena koszyka, checkout i webhook nie wymagają logowania. Zakupy działają też jako gość. Endpointy /account/* wymagają sesji klienta, a /admin/* sesji użytkownika z rolą ADMIN. Uprawnienia sprawdza wyłącznie API, przy każdym żądaniu i dla każdego rekordu (klient widzi tylko swoje zamówienia i adresy).

Sesję otwiera POST /auth/login albo POST /auth/register. Oba ustawiają ciasteczko:

CiasteczkoOpis
lumen_sessionLosowy token (32 bajty). W bazie zapisany jest tylko jego skrót SHA-256. Flagi: HttpOnly, SameSite=Lax, Path=/, Secure na produkcji. Ważne 30 dni. Reset hasła unieważnia wszystkie sesje.

Wymagania dla żądań:

NagłówekOpis
Cookielumen_session=…. Przeglądarka dołącza je sama (to samo pochodzenie dzięki rewrite /api/*), w curl: -b.
Content-Typeapplication/json dla każdego żądania z treścią (POST, PUT, PATCH).
OriginOpcjonalny. Jeśli jest wysłany przy POST/PUT/PATCH/DELETE, musi wskazywać WEB_URL albo adres z ALLOWED_ORIGINS, inaczej 403 origin_not_allowed.

Przykład (curl): logowanie i pierwsze żądanie z tą samą sesją:

curl -c cookies.txt -H 'Content-Type: application/json' \
  -d '{"email":"anna.nowak@example.com","password":"…"}' \
  https://lumen.com/api/auth/login

curl -b cookies.txt https://lumen.com/api/account/orders

Brak sesji → 401, {"error": "unauthorized"}. Sesja bez roli admina na /admin/* → 403, {"error": "forbidden"}.

LimitWartość
Globalny300 żądań na minutę z jednego IP
/auth/register, /auth/login, /auth/password-reset/*5 żądań na minutę
/checkout10 żądań na minutę

/cart/quote60 żądań na minutę
/webhooks/stripebez limitu (podpis Stripe)

  "error": "rate_limited"

Konwencje i błędy

ZasadaOpis
FormatJSON w UTF-8. Wyjątek: DELETE /account/addresses/:id zwraca 204 bez treści.
CenyLiczby całkowite w groszach (PLN), pola z końcówką Grosze: 15900 = 159,00 zł. Cenę zawsze liczy serwer z bazy, klient wysyła tylko variantId i ilość.
DatyISO 8601 w UTC, np. 2026-10-11T14:22:58.820Z.
IdentyfikatoryCUID (cmv54jvex00005e8obintkd10). Produkty mają też slug (cedr-i-dym), warianty sku (LUM-CEDR-I-DYM-180), zamówienia numer LM-RRMMDD-XXXX.
JęzykParametr locale: pl (domyślny) albo en. Wpływa na nazwy, opisy i alt zdjęć.
DostawaCOURIER 19,99 zł, PARCEL_LOCKER 14,99 zł, darmowa od 300 zł. Tylko Polska.
HoneypotFormularze publiczne mają pole website. Musi być puste albo pominięte.
Maks. rozmiar treści64 kB na żądanie.

Każdy błąd ma pole error z kodem. Błąd walidacji ma dodatkowo listę issues (ścieżka pola, kod, opis):

  "issues": [
    {
      "path": "postalCode",
      "code": "invalid_format",
      "message": "Invalid string: must match pattern /^\\d{2}-\\d{3}$/"
    },
    {
      "path": "phone",
      "code": "invalid_format",
      "message": "Invalid string: must match pattern /^\\+?[0-9 ()-]{9,20}$/"
    }
  ]
}
KodKiedy
400validation_error (z issues) albo kod biznesowy, np. invalid_token, invalid_transition, tracking_required.
401unauthorized (brak sesji) albo invalid_credentials (złe dane logowania).
403forbidden (brak roli admina) albo origin_not_allowed (obcy Origin).
404Nie ma zasobu (product_not_found, order_not_found, address_not_found, variant_not_found) albo endpointu (not_found).
409Konflikt: email_taken, cart_changed (brak towaru przy checkoutcie), address_limit (maks. 10 adresów).
429rate_limited, nagłówek Retry-After w sekundach.
500internal_error. Szczegóły tylko w logu serwera.
503payments_unavailable: brak kluczy Stripe na serwerze.

GET/checkout/confirmation

Strona „dziękujemy” po powrocie ze Stripe. Sprawdza PaymentIntent i zwraca zamówienie. Jeśli płatność już przeszła, a webhook jeszcze nie dotarł, oznacza zamówienie jako opłacone (idempotentnie).
